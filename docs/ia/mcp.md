# Servidores MCP usados

| Servidor | Para qué se usa |
|---|---|
| Playwright | Abrir el juego en el navegador, tomar capturas (`docs/capturas`), comprobar visualmente escenas y flujos. |
| Context7 | Consultar documentación vigente de Phaser 3, Vite, Vitest y TypeScript antes de escribir código que dependa de sus APIs. |

La configuración local (`.mcp.json`) no se versiona; es equivalente a ejecutar `npx @playwright/mcp` y `npx @upstash/context7-mcp`.
